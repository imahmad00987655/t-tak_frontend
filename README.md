# t-tak frontend

## Local setup

1. Install dependencies:
   - `npm install`
2. Create env file:
   - copy `.env.example` to `.env`
3. Set API URL in `.env`:
   - `VITE_API_URL=http://127.0.0.1:3001`
4. Start frontend:
   - `npm run dev`

## Production env

```env
VITE_API_URL=https://your-backend-domain.com
```

## Build

- `npm run build`
- Output folder: `dist/`
